# Добавить компанию в рейтинг

Компания по аудиту информационной безопасности может подать заявку на включение в рейтинг или исправить данные о себе. Редакция оценивает каждую компанию по общей шкале из 100 баллов. Включение в рейтинг бесплатное, место не обещается.

**Email редакции:** redakciya@rejting-kompanij-po-auditu-bezopasnosti.com

## Какие данные приложить к заявке

Заявка рассматривается быстрее, если в ней есть ссылки на открытые подтверждения по шести критериям методологии:

- Номер лицензии ФСТЭК на техническую защиту конфиденциальной информации (ТЗКИ) нужен для проверки в реестре.
- Ссылки на уязвимости в Банке данных угроз ФСТЭК (БДУ) или в CVE (Common Vulnerabilities and Exposures) подтверждают исследования.
- Ссылка на технический блог показывает разборы уязвимостей.
- Описание методологии называет стандарты и этапы работ.
- Описание состава отчёта или обезличенный образец показывает формат результата.
- Перечень видов технического аудита и опубликованные сроки завершают заявку.

## Как проходит оценка

Шаг 1: редакция проверяет каждую ссылку и сохраняет дату проверки. Шаг 2: редакция считает баллы по шкале со страницы [«Методология»](https://rejting-kompanij-po-auditu-bezopasnosti.com/metodologiya/). Шаг 3: результат оценки публикуется при следующей ежеквартальной сверке, запись появляется в журнале изменений.

## Исправить данные о компании

Компания из рейтинга отправляет через ту же форму ссылку на подтверждение новых данных. Редакция отвечает в срок до 10 рабочих дней. Без ссылки на подтверждение данные не меняются.

## Форма заявки

Форма содержит пять обязательных полей:

- Переключатель задаёт тип обращения: включить компанию или исправить данные.
- Поле «Название компании» заполняется текстом.
- Поле «Ссылки на подтверждения» принимает одну или несколько ссылок.
- Поле «Email для ответа» принимает адрес для ответа редакции.
- Чекбокс подтверждает согласие на обработку данных по [правовой информации](https://rejting-kompanij-po-auditu-bezopasnosti.com/pravovaya-informaciya/#konfidencialnost).
